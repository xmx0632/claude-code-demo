## 1. 项目概览

### 1.1 项目名称
TodoList - 待办事项管理系统

### 1.2 项目背景
演示如何使用 SDLC Framework 完整开发一个前后端分离的待办事项管理应用。本项目将展示框架的 15 个阶段、8 种角色和 SDD 增强功能的完整应用。

### 1.3 项目目标
- **S**: 开发一个完整的待办事项管理系统
- **M**: 支持用户注册、任务 CRUD、分类管理
- **A**: 使用 Spring Boot + Vue3 技术栈实现
- **R**: 作为 SDLC 框架演示项目
- **T**: 1 周内完成 MVP

### 1.4 项目范围
**包含**:
- 用户注册/登录/登出
- 任务的创建、查看、修改、删除
- 任务状态管理（待办/进行中/已完成）
- 任务优先级设置（高/中/低）
- 任务分类管理

**不包含**:
- 移动端 APP
- 第三方登录（OAuth）
- 任务分享功能
- 多语言支持

---

## 2. 背景和上下文

### 2.1 业务问题
用户需要一个简单高效的工具来管理日常待办事项，记录需要完成的任务，追踪任务进度。

### 2.2 当前状态
无现有系统，从零开始开发。

### 2.3 期望状态
- 用户可以通过 Web 界面管理待办事项
- 数据安全存储，按用户隔离
- 界面简洁，操作便捷

### 2.4 业务价值
- **演示价值**: 展示 SDLC Framework 的完整开发流程
- **学习价值**: 作为前后端分离开发的参考示例
- **实用价值**: 可直接用于个人任务管理

## 4. 功能需求

### FR-001: 用户注册

**描述**: 用户可以通过邮箱注册新账号

**用户故事**: 作为新用户，我想要注册账号，以便使用待办事项管理功能

**功能详情**:
1. 输入邮箱地址
2. 输入密码（需确认）
3. 输入昵称（可选）
4. 提交注册

**验收标准**:
- [ ] 邮箱格式验证
- [ ] 密码长度 >= 6 位
- [ ] 邮箱不能重复注册
- [ ] 密码 BCrypt 加密存储

**优先级**: P0

---

### FR-002: 用户登录

**描述**: 已注册用户可以通过邮箱和密码登录系统

**用户故事**: 作为已注册用户，我想要登录系统，以便访问我的待办事项

**功能详情**:
1. 输入邮箱地址
2. 输入密码
3. 提交登录
4. 获取 JWT Token

**验收标准**:
- [ ] 验证邮箱和密码
- [ ] 登录成功返回 JWT Token
- [ ] Token 有效期 24 小时
- [ ] 错误提示不泄露敏感信息

**优先级**: P0

---

### FR-003: 创建任务

**描述**: 登录用户可以创建新的待办任务

**用户故事**: 作为登录用户，我想要创建任务，以便记录我需要完成的事项

**功能详情**:
1. 输入任务标题（必填）
2. 输入任务描述（可选）
3. 选择优先级（高/中/低，默认中）
4. 选择分类（可选）
5. 设置截止日期（可选）

**验收标准**:
- [ ] 标题不能为空，最大 200 字符
- [ ] 创建后状态默认为"待办"
- [ ] 任务自动关联当前用户

**优先级**: P0

---

### FR-004: 查看任务列表

**描述**: 登录用户可以查看自己的任务列表

**用户故事**: 作为登录用户，我想要查看任务列表，以便了解所有待办事项

**功能详情**:
1. 分页显示任务列表
2. 按状态筛选（全部/待办/进行中/已完成）
3. 按优先级筛选
4. 按分类筛选
5. 按创建时间倒序排列

**验收标准**:
- [ ] 只显示当前用户的任务
- [ ] 支持分页（每页 10 条）
- [ ] 支持多条件组合筛选

**优先级**: P0

---

### FR-005: 更新任务

**描述**: 登录用户可以修改自己的任务

**用户故事**: 作为登录用户，我想要修改任务内容，以便更新任务信息

**功能详情**:
1. 修改任务标题
2. 修改任务描述
3. 修改优先级
4. 修改分类
5. 修改截止日期

**验收标准**:
- [ ] 只能修改自己的任务
- [ ] 修改后更新时间自动更新

**优先级**: P0

---

### FR-006: 删除任务

**描述**: 登录用户可以删除自己的任务

**用户故事**: 作为登录用户，我想要删除任务，以便清理不需要的任务

**验收标准**:
- [ ] 只能删除自己的任务
- [ ] 删除前需确认
- [ ] 删除成功后从列表移除

**优先级**: P0

---

### FR-007: 完成任务

**描述**: 登录用户可以标记任务为已完成

**用户故事**: 作为登录用户，我想要标记任务完成，以便追踪我的进度

**功能详情**:
1. 点击切换完成状态
2. 记录完成时间

**验收标准**:
- [ ] 状态切换为"已完成"
- [ ] 记录完成时间
- [ ] 支持取消完成状态

**优先级**: P0

---

### FR-008: 分类管理

**描述**: 登录用户可以创建和管理任务分类

**用户故事**: 作为登录用户，我想要管理分类，以便更好地组织任务

**功能详情**:
1. 创建分类（名称、颜色）
2. 编辑分类
3. 删除分类

**验收标准**:
- [ ] 分类按用户隔离
- [ ] 删除分类时任务保留（分类置空）
- [ ] 支持自定义颜色

**优先级**: P1
