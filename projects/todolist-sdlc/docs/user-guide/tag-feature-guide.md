## 1. 功能概述

任务标签功能允许您为任务添加自定义标签，通过颜色和名称对任务进行分类管理。

### 1.1 主要功能

- **标签管理**：创建、编辑、删除自定义标签
- **任务标签**：为任务添加多个标签
- **标签筛选**：通过标签快速找到相关任务

### 1.2 应用场景

| 场景 | 标签示例 | 用途 |
|------|----------|------|
| 工作项目 | 工作、重要、紧急 | 区分工作任务优先级 |
| 个人生活 | 学习、健康、娱乐 | 管理个人事务 |
| 项目管理 | 需求、开发、测试 | 跟踪项目阶段 |

## 2. 创建标签

### 2.1 进入标签管理

1. 点击左侧导航栏的「标签」图标
2. 进入标签管理页面

### 2.2 创建新标签

1. 点击「创建标签」按钮
2. 填写标签信息：
   - **标签名称**：1-20 个字符
   - **标签颜色**：选择预设颜色或自定义颜色
3. 点击「保存」

### 2.3 标签颜色说明

| 颜色 | HEX值 | 推荐用途 |
|------|-------|----------|
| 🔴 红色 | #FF6B6B | 紧急、重要 |
| 🟠 橙色 | #FFA07A | 提醒、待办 |
| 🟡 黄色 | #F7DC6F | 临时、计划 |
| 🟢 绿色 | #4ECDC4 | 完成、正常 |
| 🔵 蓝色 | #5C9DED | 工作、学习 |
| 🟣 紫色 | #BB8FCE | 个人、创意 |
| 🩷 粉色 | #FF9FF3 | 生活、娱乐 |

### 2.4 注意事项

- 标签名称在同一用户下必须唯一
- 颜色格式为 HEX 格式（#RRGGBB）
- 删除标签会同时删除所有任务的该标签关联

## 3. 管理标签

### 3.1 查看标签列表

标签列表显示以下信息：
- 标签颜色和名称
- 关联的任务数量
- 创建时间

### 3.2 编辑标签

1. 在标签列表中找到要编辑的标签
2. 点击「编辑」按钮
3. 修改标签名称或颜色
4. 点击「保存」

**注意**：修改标签名称会自动更新所有已关联该标签的任务。

### 3.3 删除标签

1. 在标签列表中找到要删除的标签
2. 点击「删除」按钮
3. 确认删除

**警告**：删除标签会：
- 删除该标签
- 移除所有任务的该标签关联
- 此操作不可恢复

## 4. 为任务添加标签

### 4.1 单个任务添加标签

1. 打开任务详情
2. 点击「标签」区域
3. 在弹出的标签选择器中选择标签
4. 点击「确认」

### 4.2 批量添加标签

1. 在任务列表中勾选多个任务
2. 点击「批量操作」→「添加标签」
3. 选择要添加的标签
4. 点击「确认」

### 4.3 移除任务标签

1. 打开任务详情
2. 在「标签」区域找到要移除的标签
3. 点击标签上的「×」按钮

### 4.4 替换任务标签

1. 打开任务详情
2. 点击「标签」区域
3. 清除现有标签或直接选择新标签
4. 点击「确认」

## 5. 使用标签筛选任务

### 5.1 单标签筛选

1. 在任务列表页面点击「筛选」按钮
2. 选择一个标签
3. 查看包含该标签的所有任务

### 5.2 多标签筛选（AND 逻辑）

当选择多个标签时，系统使用 **AND 逻辑**：
- 只显示**同时包含所有选中标签**的任务

**示例**：
- 选择「工作」+「重要」：只显示既有「工作」标签又有「重要」标签的任务
- 选择「工作」+「重要」+「紧急」：只显示同时拥有这三个标签的任务

### 5.3 清除筛选

1. 点击筛选栏的「清除」按钮
2. 或取消已选择的标签

## 6. 常见问题

### Q1: 标签名称可以修改吗？

**A**: 可以。编辑标签名称后，所有已关联该标签的任务会自动更新。

### Q2: 一个任务可以添加多少个标签？

**A**: 没有数量限制。建议根据实际需要合理添加，避免标签过多影响管理。

### Q3: 删除标签会影响任务吗？

**A**: 删除标签不会删除任务本身，只会移除任务的该标签关联。

### Q4: 标签可以排序吗？

**A**: 标签默认按创建时间倒序排列。目前不支持自定义排序。

### Q5: 为什么选择多个标签后没有结果？

**A**: 多标签筛选使用 AND 逻辑，需要任务**同时包含所有选中标签**才会显示。尝试减少选中的标签数量。

### Q6: 标签颜色有特殊含义吗？

**A**: 标签颜色完全由用户自定义，用于区分不同类型的任务。系统不强制颜色的含义。

### Q7: 可以复制其他用户的标签吗？

**A**: 不可以。标签是用户私有的，每个用户需要创建自己的标签。

### Q8: 标签搜索支持模糊匹配吗？

**A**: 支持。在标签管理页面搜索时，输入标签名称的部分字符即可匹配。
