## 1. 产品简介

- ✅ 快速创建和管理任务

## 2. 快速开始

### 2.1 注册账号

1. 打开应用，点击"注册"
2. 输入邮箱地址
3. 设置密码（至少 6 位）
4. 点击"注册"按钮

### 2.2 登录系统

1. 输入注册的邮箱
2. 输入密码
3. 点击"登录"按钮

## 3. 功能说明

### 3.1 任务管理

#### 创建任务

1. 点击右上角 **+新建** 按钮
2. 填写任务信息：
   - **标题**（必填）：任务名称
   - **描述**（可选）：任务详情
   - **优先级**：高 / 中 / 低
   - **分类**：选择或创建分类
   - **截止日期**（可选）
3. 点击 **保存** 完成

#### 查看任务

- 任务列表默认显示所有待办任务
- 可通过顶部标签筛选：
  - **全部**：所有任务
  - **待办**：未完成的任务
  - **已完成**：已完成的任务

#### 完成任务

- 点击任务前的 **复选框** 标记完成
- 已完成任务会显示删除线
- 再次点击可取消完成状态

#### 编辑任务

1. 点击任务标题进入详情
2. 修改需要更新的内容
3. 点击 **保存** 按钮

#### 删除任务

1. 将鼠标悬停在任务上
2. 点击 **删除** 图标
3. 确认删除操作

### 3.2 分类管理

#### 创建分类

1. 进入 **分类管理** 页面
2. 点击 **新建分类**
3. 输入分类名称和选择颜色
4. 点击 **保存**

#### 使用分类

- 创建任务时可选择分类
- 任务列表可按分类筛选
- 侧边栏显示分类快捷入口

### 3.3 优先级说明

| 级别 | 颜色 | 说明 |
|------|------|------|
| 高 | 🔴 红色 | 紧急重要，优先处理 |
| 中 | 🟡 黄色 | 常规任务 |
| 低 | 🟢 绿色 | 可稍后处理 |

## 4. 常见问题

### Q1: 忘记密码怎么办？

目前请联系管理员重置密码。

### Q2: 任务数据会丢失吗？

数据存储在云端服务器，自动备份，不会丢失。

### Q3: 支持哪些浏览器？

支持 Chrome、Firefox、Safari、Edge 等主流浏览器的最新版本。
