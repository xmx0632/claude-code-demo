# 图书库存管理系统 - 需求设计文档

## 1. 项目概述

### 1.1 项目名称
图书库存管理系统 (Library Inventory Management System)

### 1.2 项目目标
构建一个轻量级的图书库存管理系统，实现对图书信息、库存数量的有效管理，支持图书入库、出库、查询统计等核心功能。

### 1.3 技术栈
| 层级 | 技术选型 | 版本 |
|------|----------|------|
| 前端 | Vue.js | 3.x |
| 后端 | Spring Boot | 3.x |
| 数据库 | SQLite | 3.x |
| 数据库版本管理 | Flyway | 9.x |
| 构建工具 | Maven | - |

---

## 2. 功能需求

### 2.1 核心功能模块

#### 2.1.1 图书管理
| 功能 | 描述 |
|------|------|
| 新增图书 | 录入图书基本信息（书名、作者、ISBN、分类、价格等） |
| 编辑图书 | 修改图书信息 |
| 删除图书 | 删除图书记录（需确认） |
| 查看图书详情 | 查看图书完整信息 |

#### 2.1.2 库存管理
| 功能 | 描述 |
|------|------|
| 入库操作 | 增加图书库存数量，记录入库时间和操作人 |
| 出库操作 | 减少图书库存数量，记录出库时间和操作人 |
| 库存查询 | 查看当前库存数量 |
| 库存预警 | 库存低于阈值时显示警告 |
| 库存日志 | 查看所有入库出库记录 |

#### 2.1.3 分类管理
| 功能 | 描述 |
|------|------|
| 新增分类 | 创建图书分类 |
| 编辑分类 | 修改分类名称 |
| 删除分类 | 删除分类（需检查是否有图书使用） |
| 分类列表 | 查看所有分类 |

#### 2.1.4 查询统计
| 功能 | 描述 |
|------|------|
| 图书搜索 | 按书名、作者、ISBN、分类搜索 |
| 高级筛选 | 多条件组合查询 |
| 库存统计 | 按分类统计库存数量 |
| 入库出库统计 | 按时间段统计入库出库情况 |

### 2.2 非功能需求

| 需求项 | 说明 |
|--------|------|
| 响应时间 | 页面加载时间 < 2s，API响应 < 500ms |
| 并发用户 | 支持 10 人同时使用 |
| 数据一致性 | 库存操作需保证数据一致性 |
| 易用性 | 界面简洁直观，操作简单 |
| 可维护性 | 代码结构清晰，易于扩展 |

## 4. 数据模型设计

### 4.1 核心实体

#### 4.1.1 图书 (book)
| 字段 | 类型 | 说明 | 约束 |
|------|------|------|------|
| id | BIGINT | 主键 | PK, AUTO_INCREMENT |
| title | VARCHAR(200) | 书名 | NOT NULL |
| author | VARCHAR(100) | 作者 | NOT NULL |
| isbn | VARCHAR(20) | ISBN编号 | UNIQUE |
| category_id | BIGINT | 分类ID | FK |
| price | DECIMAL(10,2) | 价格 | |
| publisher | VARCHAR(100) | 出版社 | |
| publish_date | DATE | 出版日期 | |
| description | TEXT | 图书描述 | |
| stock_quantity | INT | 库存数量 | DEFAULT 0 |
| min_stock | INT | 最小库存预警值 | DEFAULT 5 |
| created_at | TIMESTAMP | 创建时间 | |
| updated_at | TIMESTAMP | 更新时间 | |

#### 4.1.2 分类 (category)
| 字段 | 类型 | 说明 | 约束 |
|------|------|------|------|
| id | BIGINT | 主键 | PK, AUTO_INCREMENT |
| name | VARCHAR(50) | 分类名称 | NOT NULL, UNIQUE |
| description | VARCHAR(200) | 分类描述 | |
| created_at | TIMESTAMP | 创建时间 | |
| updated_at | TIMESTAMP | 更新时间 | |

#### 4.1.3 库存记录 (stock_log)
| 字段 | 类型 | 说明 | 约束 |
|------|------|------|------|
| id | BIGINT | 主键 | PK, AUTO_INCREMENT |
| book_id | BIGINT | 图书ID | FK |
| type | VARCHAR(10) | 操作类型 | IN/OUT |
| quantity | INT | 数量 | NOT NULL |
| before_quantity | INT | 操作前数量 | |
| after_quantity | INT | 操作后数量 | |
| remark | VARCHAR(200) | 备注 | |
| created_at | TIMESTAMP | 操作时间 | |

## 5. API 接口设计

### 5.1 图书接口

| 方法 | 路径 | 描述 |
|------|------|------|
| GET | /api/books | 获取图书列表（分页、搜索） |
| GET | /api/books/{id} | 获取图书详情 |
| POST | /api/books | 新增图书 |
| PUT | /api/books/{id} | 更新图书 |
| DELETE | /api/books/{id} | 删除图书 |
| POST | /api/books/{id}/stock-in | 入库 |
| POST | /api/books/{id}/stock-out | 出库 |
| GET | /api/books/{id}/stock-logs | 获取库存操作日志 |

### 5.2 分类接口

| 方法 | 路径 | 描述 |
|------|------|------|
| GET | /api/categories | 获取分类列表 |
| POST | /api/categories | 新增分类 |
| PUT | /api/categories/{id} | 更新分类 |
| DELETE | /api/categories/{id} | 删除分类 |

### 5.3 统计接口

| 方法 | 路径 | 描述 |
|------|------|------|
| GET | /api/stats/summary | 获取统计概览 |
| GET | /api/stats/low-stock | 获取低库存图书 |

## 6. 前端页面设计

### 6.1 页面结构

```
├── 登录页 (后续扩展)
├── 主布局
│   ├── 侧边栏导航
│   └── 内容区域
└── 页面
    ├── 仪表盘 (Dashboard)
    │   └── 统计概览、低库存预警
    ├── 图书管理
    │   ├── 图书列表 (搜索、分页)
    │   ├── 新增/编辑图书
    │   └── 库存操作
    ├── 分类管理
    │   └── 分类列表
    └── 库存日志
        └── 操作记录查询
```

### 6.2 核心页面

| 页面 | 功能 |
|------|------|
| 仪表盘 | 显示图书总数、分类数、低库存预警图书 |
| 图书列表 | 展示图书列表，支持搜索、筛选、分页 |
| 图书表单 | 新增/编辑图书信息 |
| 分类管理 | 管理图书分类 |
| 库存日志 | 查看入库出库历史记录 |
