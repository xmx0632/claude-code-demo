# 图书库存管理系统 - 教学提示词文档

## 项目概述

这是一个用于教学演示的全栈 Web 应用项目，展示了如何使用现代化的技术栈构建一个完整的图书库存管理系统。

## 技术栈

| 层级 | 技术选型 | 版本 | 说明 |
|------|----------|------|------|
| 前端 | Vue.js | 3.x | 渐进式 JavaScript 框架 |
| 前端UI | Element Plus | - | Vue 3 组件库 |
| 后端 | Spring Boot | 3.x | Java 企业级开发框架 |
| 数据库 | SQLite | 3.x | 轻量级关系型数据库 |
| 数据库版本管理 | Flyway | 9.x | 数据库迁移工具 |
| 构建工具 | Maven | 3.x | Java 项目管理工具 |
| 构建工具 | Vite | 5.x | 前端构建工具 |

---

## 开发步骤

### 第一阶段：数据库设计
1. 设计数据表结构（book, category, stock_log）
2. 编写 Flyway 迁移脚本
3. 插入测试数据

### 第二阶段：后端开发
1. 创建 Spring Boot 项目骨架
2. 配置 SQLite 数据源和 JPA
3. 配置 Flyway
4. 创建实体类（Entity）
5. 创建 Repository 接口
6. 实现 Service 业务逻辑
7. 实现 Controller 接口
8. 统一异常处理和响应格式
9. 配置跨域

### 第三阶段：前端开发
1. 创建 Vue 3 + Vite 项目
2. 安装 Element Plus
3. 配置路由和状态管理
4. 封装 API 请求
5. 开发布局组件
6. 开发业务页面

### 第四阶段：联调测试
1. 启动后端服务
2. 启动前端开发服务器
3. 功能测试
4. 问题修复

## API 接口规范

### 请求格式
```
Content-Type: application/json
```

### 响应格式（统一）
```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

### 状态码规范
| code | message | 说明 |
|------|---------|------|
| 200 | success | 成功 |
| 400 | 参数错误 | 请求参数错误 |
| 404 | 资源不存在 | 资源未找到 |
| 500 | 服务器错误 | 系统异常 |

## Git 提交规范

### 提交格式
```
<type>(<scope>): <subject>

<body>

<footer>
```

### type 类型
| 类型 | 说明 |
|------|------|
| feat | 新功能 |
| fix | 修复bug |
| docs | 文档更新 |
| style | 代码格式调整 |
| refactor | 重构代码 |
| test | 测试相关 |
| chore | 构建/工具相关 |

### 示例
```
feat(backend): 添加图书管理接口

- 实现图书列表查询
- 实现图书新增/编辑/删除
- 实现库存入库/出库操作
```

## 教学重点

### 后端教学点
1. **分层架构**：Controller → Service → Repository
2. **JPA 使用**：实体定义、关联关系、查询方法
3. **Flyway 迁移**：版本化数据库管理
4. **统一响应**：Result 封装
5. **异常处理**：@ControllerAdvice

### 前端教学点
1. **Vue 3 组合式 API**：setup, ref, reactive, computed
2. **路由管理**：路由配置、路由守卫
3. **状态管理**：Pinia store 定义和使用
4. **组件通信**：props, emit, provide/inject
5. **请求封装**：axios 拦截器

## 运行说明

### 后端启动
```bash
cd backend
mvn spring-boot:run
```
访问：http://localhost:8080

### 前端启动
```bash
cd frontend
npm install
npm run dev
```
访问：http://localhost:5173

---

## 注意事项

1. **数据库位置**：`backend/data/library.db`，首次启动会自动创建
2. **端口配置**：后端 8080，前端 5173
3. **跨域配置**：已配置 CORS，允许前端访问
4. **测试数据**：Flyway 会自动插入初始数据
