# 图书库存管理系统 - 启动指南

## 环境要求

### 后端
- JDK 17+
- Maven 3.x

### 前端
- Node.js 18+
- npm 或 yarn

---

## 启动步骤

### 1. 启动后端

```bash
cd library-management-system/backend

# 首次启动会自动下载依赖
mvn spring-boot:run
```

后端服务启动后，访问: http://localhost:8080

首次启动会自动创建数据库并插入测试数据。

### 2. 启动前端

```bash
cd library-management-system/frontend

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

前端服务启动后，访问: http://localhost:5173

## 常见问题

### 后端启动失败
- 检查 JDK 版本是否为 17+
- 检查 8080 端口是否被占用

### 前端启动失败
- 检查 Node.js 版本是否为 18+
- 删除 node_modules 后重新 `npm install`

### 数据库连接失败
- 检查 backend/data/ 目录是否有写权限
- 删除 library.db 后重新启动后端
