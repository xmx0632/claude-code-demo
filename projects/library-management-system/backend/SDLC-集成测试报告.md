## 4. 问题解决记录

### 4.1 已解决的问题

#### 问题 1: HSQLDB 保留字冲突
**问题描述**:
```
InvalidDataAccessResourceUsageException: user lacks privilege or object not found: BOOK
```

**根本原因**:
- `BOOK` 是 HSQLDB 的保留字
- 表名 `book` 与保留字冲突

**解决方案**:
- 修改表名: `book` → `books`
- 修改表名: `category` → `categories`
- 修改表名: `stock_log` → `stock_logs`

**影响范围**: 已解决

#### 问题 2: 分页参数不匹配
**问题描述**:
测试使用 `page=0` (0-based)，API 使用 `page=1` (1-based)

**解决方案**:
- 更新测试代码使用 `page=1`
- 更新响应断言使用正确的字段名 (`records`, `total`, `pages`)

**影响范围**: 已解决

#### 问题 3: 测试数据依赖问题
**问题描述**:
多个测试依赖 `testBookId` 静态变量，但 `@BeforeEach` 清空数据库后 ID 变失效

**解决方案**:
- 每个测试创建独立的测试数据
- 使用辅助方法 `createTestBook()` 和 `createLowStockBook()`

**影响范围**: 已解决
