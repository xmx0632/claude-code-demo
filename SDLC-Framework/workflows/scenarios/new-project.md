# 新项目开发场景

## 场景描述
适用于从零开始的新项目开发，需要完整的需求分析、架构设计和开发流程。

## 触发条件
- 项目目录为空或仅包含初始化文件
- 不存在 `pom.xml` 或 `package.json`

## 执行流程

```
[开始]
   │
   ▼
[需求分析] ──▶ [需求文档.md]
   │
   ▼
[架构设计] ──▶ [架构文档.md]
   │          ├─▶ [API规范.md]
   │          └─▶ [数据模型.md]
   │
   ▼
[代码开发]
   │
   ▼
[测试验证] ──▶ [测试计划.md]
   │
   ▼
[部署上线] ─▶ [部署文档.md]
```

## 必需文档 (6个)

1. **需求文档** (Requirements.md)
2. **架构文档** (Architecture.md)
3. **API规范** (API-Specs.md)
4. **数据模型** (Data-Models.md)
5. **测试计划** (Test-Plan.md)
6. **部署文档** (Deployment.md)

## 可选文档

- 用户手册 (User-Manual.md)
- 运维手册 (Operations-Manual.md)
- 升级指南 (Upgrade-Guide.md)

## 质量门禁

- [ ] 需求文档已批准
- [ ] 架构文档已审查
- [ ] API 规范已定义
- [ ] 测试用例已覆盖
- [ ] 部署方案已验证

## 预计时间

- 小型项目: 1-2 周
- 中型项目: 2-4 周
- 大型项目: 4-8 周
