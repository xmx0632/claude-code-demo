# User Manual Skill

> 阶段 12: 用户手册

---

## 触发命令

```bash
/user-manual
```

---

## 阶段目标

编写面向最终用户的操作手册和帮助文档。

---

## 输入

- 完整系统
- 功能清单
- 用户角色定义

---

## 输出

| 产出物 | 文件 | 说明 |
|--------|------|------|
| 用户手册 | docs/user/user-manual.md | 完整操作指南 |
| 快速入门 | docs/user/quick-start.md | 快速上手指南 |
| FAQ | docs/user/faq.md | 常见问题 |

---

## 文档结构

```markdown
# 系统名称 用户手册

## 1. 概述
### 1.1 系统简介
### 1.2 适用对象
### 1.3 功能概览

## 2. 快速入门
### 2.1 注册账号
### 2.2 首次登录
### 2.3 基本操作

## 3. 功能详解
### 3.1 [功能模块 A]
### 3.2 [功能模块 B]

## 4. 常见问题 (FAQ)

## 5. 联系支持
```

---

## 质量门禁

- [ ] 覆盖所有用户功能
- [ ] 包含截图说明
- [ ] 语言简洁易懂
- [ ] 已通过用户评审
