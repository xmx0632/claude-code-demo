# Test Case Writing Skill

> 阶段 10: 测试用例编写

---

## 触发命令

```bash
/test-cases <feature_name>
```

---

## 阶段目标

编写详细的测试用例，覆盖所有功能点和边界条件。

---

## 输入

- 需求规格说明书 (阶段 1 产出)
- API 设计文档 (阶段 4 产出)
- 验收标准

---

## 输出

| 产出物 | 文件 | 说明 |
|--------|------|------|
| 测试用例文档 | docs/testing/test-cases.md | 详细测试用例 |
| 测试数据 | tests/fixtures/ | 测试数据集 |

---

## 测试用例格式

```markdown
### TC-001: 用户登录成功

**前置条件**
- 用户已注册
- 用户状态为激活

**测试步骤**
1. 打开登录页面
2. 输入有效用户名
3. 输入有效密码
4. 点击登录按钮

**预期结果**
- 登录成功
- 跳转到首页
- 显示用户信息

**优先级**: P0
**类型**: 正向测试
```

---

## 质量门禁

- [ ] 覆盖所有功能点
- [ ] 包含边界条件
- [ ] 包含异常场景
- [ ] 用例可执行
