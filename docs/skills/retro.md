# sdlc-retro 使用指南

周度工程复盘工具，分析提交历史、工作模式和代码质量指标，支持团队感知和贡献者评估。

## 🚀 快速开始

```bash
# 执行周度复盘
/sdlc-retro

# 指定时间范围
/sdlc-retro --since="2 weeks ago"

# 指定作者
/sdlc-retro --author="张三"
```

## 📋 核心功能

| 功能 | 说明 |
|------|------|
| **提交历史分析** | 统计提交频率、时段分布 |
| **工作模式识别** | 识别工作习惯和模式 |
| **代码质量指标** | 分析代码变更量和复杂度 |
| **团队协作评估** | 评估团队成员贡献度 |
| **成长空间分析** | 识别优势和改进点 |

## 🎯 分析维度

### 1. 提交活跃度

- 总提交数
- 日均提交数
- 提交时段分布（工作日/周末）
- 最活跃的时间段

### 2. 代码变更

- 新增代码行数
- 删除代码行数
- 修改文件数量
- 文件类型分布

### 3. 工作模式

- 连续工作模式
- 突击式提交模式
- 协作模式（多人同时提交）

### 4. 质量指标

- 平均提交消息长度
- Bug 修复提交占比
- 重构提交占比
- 文档更新频率

## ⚙️ 配置选项

### 时间范围

```bash
# 最近一周
/sdlc-retro --since="1 week ago"

# 最近两周
/sdlc-retro --since="2 weeks ago"

# 自定义日期
/sdlc-retro --since="2026-03-01"
```

### 过滤选项

```bash
# 按作者过滤
/sdlc-retro --author="张三"

# 按文件类型过滤
/sdlc-retro --ext=".java"

# 按分支过滤
/sdlc-retro --branch="develop"
```

### 输出格式

```bash
# Markdown 格式
/sdlc-retro --format=markdown

# JSON 格式
/sdlc-retro --format=json

# HTML 格式
/sdlc-retro --format=html
```

## 🔧 使用场景

### 场景 1：团队周会

```bash
/sdlc-retro --since="1 week ago" --format=markdown
```

**用途**：
- 回顾本周工作进展
- 识别团队成员贡献
- 发现潜在问题

### 场景 2：绩效评估

```bash
/sdlc-retro --author="张三" --since="1 month ago"
```

**用途**：
- 评估个人工作量
- 分析工作质量
- 制定成长计划

### 场景 3：质量分析

```bash
/sdlc-retro --format=html > report.html
```

**用途**：
- 生成可视化报告
- 归档历史数据
- 团队知识分享

## 🐛 常见问题

### Q: 如何处理大型仓库？
**A**: 可以指定目录或排除特定路径

### Q: 如何识别多账号提交？
**A**: 通过邮箱地址识别，可配置别名映射

### Q: 如何处理历史数据迁移？
**A**: 支持从 Git log 导入历史数据
